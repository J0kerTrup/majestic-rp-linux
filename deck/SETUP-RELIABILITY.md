# Надёжность мастера Steam Deck

Область: GTA V Legacy Rockstar Edition, Python 3.11+, Linux. Это проверка установщика; успешный вход на сервер требует отдельной проверки игрой.

## Правила

- Steam и Proton определяются общим детектором раннера, включая Steam-библиотеки. Поиск игры проверяет `GTA5.exe` без учёта регистра, а не название каталога.
- Явный/сохранённый путь имеет приоритет. Недоступная SD-карта не вызывает переключение на другую игру. При нескольких кандидатах нужен выбор.
- Перед изменениями проверяются конфликтующие ссылки/каталоги, доступ на запись, формат существующего реестра и видимые процессы с WINEPREFIX этого префикса. Параллельные процессы Python-мастера блокируются. Проверка процессов не исключает запуск Wine после проверки: держите игру закрытой.
- Существующие данные Rockstar не перезаписываются. Файлы авторизации не печатаются в диагностике.
- Настройки пользователя сохраняются; обновляются выбранные пути и точная сигнатура старого DNS-обхода. Новые defaults находятся в `majestic-runner.defaults.conf`.
- Регистровые блоки обновляются без дублей. Версия игры больше не выдумывается/не закрепляется новым патчем. Чужие значения сохраняются.
- Изменяемые конфиги, реестр и Steam VDF получают первую резервную копию `.before-deck-setup`; запись выполняется через временный файл и replace. Ярлыки редактируются только при закрытом Steam.
- Незавершённая новая загрузка установщика Majestic не становится файлом кэша. Существующий ранее повреждённый кэш автоматически не распознаётся.

## Проверка

Из корня репозитория:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
bash -n deck/deck-setup.sh
python3 deck/scripts/setup_rockstar_prefix.py --check
```

Автотесты используют временные каталоги. Они не запускают игру, не скачивают лаунчеры и не меняют пользовательский префикс.

## Ограничения и откат

Установка состоит из нескольких шагов, а не одной транзакции. При ошибке часть предыдущих шагов может быть завершена. Повторите шаг после устранения причины. Для отката восстановите нужный `.before-deck-setup` при закрытой игре/Steam. Резервная копия содержит состояние до первого изменения мастером, а не обязательно перед самым последним запуском.

Обход DNS `.net → .com` имеет статус **не подтверждён в игре**, поэтому исключён из defaults. Успешное сохранение конфигурации не считается проверкой сети или авторизации. Новые патчи документируйте как: симптом → условия применения → изменение → доказательство результата → откат → проверенные версии.
